# RevoltGreen PepperRush

Expo (SDK 57) приложение. Бандл: `com.revoltgreen.pepperrush`.

## Запуск

```bash
npm install
npm start
```

Запуск: нативный сплеш (чёрный, без логотипа) → экран загрузки с прогресс-баром → меню.
Из меню пьедестал открывает таблицу лидеров, подарок — ежедневный бонус, шестерёнка —
настройки (модалка поверх меню), колесо — Wheel of Luck, Play — сам слот. Плюс рядом с
балансом (как и тап по самому балансу) открывает магазин. Переключатели в настройках
живут в локальном стейте: сохранения ещё нет.

## Слот

Базовая игра 5×3, 25 фиксированных линий, вайлд высотой в две клетки (только барабаны
2–5). Математика перенесена из `docs/reference-3-chili-charms.md`: ленты собраны под
частоты символов из §7.1, пейтейбл — из §2. Замер на 300 000 спинов даёт RTP линий
≈41 % при референсных 42.4 %, hit rate 26.6 % (27.7 %) и медиану выигрыша 0.6× ставки.

Ставка и число автоспинов выбираются в панели (тап по плашке Bet), удержание кнопки
спина включает автоспин. Выигрыш от 10× ставки показывает оверлей win, от 50× — big win
и останавливает автоспин.

Три чили-жетона копятся в горшках `COLLECT` / `MULTIPLIER` / `2X BOARD` — полный горшок
переключается на арт с чили, но бонус-раунд Hold & Win ещё не реализован: под него нет
макета. Точка подключения — `readyModes()` в `src/game/slot/pots.ts`.

У компонента `bg` в Figma два варианта — на сплеше перец в центре есть, в меню нет, поэтому
`splash/bg.jpg` и `menu/bg.jpg` это разные картинки.

## Магазин

Три пака (Starter/Premium/VIP, Figma 1:919) и баннер «1000 FREE COINS». Платёжного бэкенда
в приложении нет, поэтому кнопка с ценой просто начисляет монеты локально — тот же стаб,
что уже использует ежедневный бонус и колесо. Реальных списаний нет нигде.
